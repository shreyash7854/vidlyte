API Reference Universal URL structure for developer integration

VidLyte resolves stream manifests and regional audio dubs dynamically without requiring private API tokens or CORS pre-flight configurations.

Standard Endpoints

# TV Series Episode (TMDB)
https://{PLAYER_DOMAIN}/embed/tv/{tmdb_id}/{season}/{episode}

# Feature Movie (TMDB)
https://{PLAYER_DOMAIN}/embed/movie/{tmdb_id}

# Anime Episode (AniList)
https://{PLAYER_DOMAIN}/embed/anime/{anilist_id}/{episode}

Query Parameters

Parameter Values Description
autoplay 1 | 0 Starts media decoding on mount. Default: 1.
muted 1 | 0 Forces muted startup to bypass aggressive mobile audio policies. Default: 0.
showTitle 1 | 0 Renders the title badge and episode tag on the top left bar. Default: 1.
exit 1 | 0 Renders an exit cross button that emits a vidlyte:exit postMessage to parent frame.
uiScale 0.5 – 2.0 Multiplies typography, icon dimensions, and control padding.
controlBg solid Substitutes translucent backdrop blur with deep solid fill.
watermark URL Custom image bug overlaid on the top right corner.

Frequently Asked Architecture, hosting, and webmaster questions

Is VidLyte really free for webmasters?
Yes. There are no paid tiers, subscription limits, or required credit cards. The network is funded autonomously via configurable player monetization.
How does VidLyte protect main site uptime?
The primary domain serves developer documentation and embed codes. Streaming manifests and media segments are routed through autonomous player edge domains, insulating the core site from bandwidth spikes and takedowns.
Are regional audio dubs supported?
Yes. The player automatically resolves multi-audio tracks (English, Hindi, Spanish, Portuguese, etc.) and allows viewers to switch audio without interrupting playback.
Can I embed on WordPress or custom CMS?
Yes. Simply paste the generated standard <iframe> element into any HTML block or custom template.
