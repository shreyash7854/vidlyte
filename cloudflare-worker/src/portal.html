Frequently Asked Questions

Frequently Asked Questions

Everything you need to know about sovereign edge streaming and domain whitelisting.

✦ Do I need an API key to embed VidLyte?

No. VidLyte is designed for zero-friction integration. Simply embed the standard iframe URL with any TMDB movie or TV show ID. All metadata and streams resolve automatically.

✦ How does the multi-worker swarm failover work?

When configured, our primary gateway transparently proxies and fetches chunks through secondary edge worker relays with sub-second failover. If an upstream CDN blocks one node IP, playback transfers instantly without dropping frames.

✦ Can other webmasters scrape my deep stream URLs?

No. All manifests and chunk URLs are encrypted with ephemeral, IP-bound HMAC tokens and AES-256-GCM opaque keys. Upstream provider origins are never exposed in client inspect tools or network captures.

✦ How can I control which domains are allowed to embed?

Administrators have full domain governance inside the Domain Governance Dashboard. You can track all referer domains, view visitor metrics, and instantly block unauthorized hostnames with one click.
